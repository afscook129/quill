# Quill — Complete Build Specification

This directory contains the Quill build specification.

The full specification (v5.1) covers:
- Problem statement and credibility gap analysis
- Persona loops (vibe coder, developer, domain expert, team lead, org)
- CLI experience and command reference
- MCP server tool definitions
- Integration matrix (Claude Code, Cursor, VS Code, Windsurf, Zed, Codex, Gemini CLI, Lovable, v0, Replit)
- Manifest and lock file schemas
- Intelligence layer (registry, search ranking, drift detection)
- Security model (Sigstore, permissions, SBOM)
- Implementation phases

See the root README.md for the public-facing overview.
